English Version

Exam

The passing score is 750. Of the 65 questions, 50 affect your score.

Domain 1: Network Design — 30%

Domain 2: Network Implementation — 26%

  • TGW
  • Site-to-Site VPN = on-premises environment + Amazon VPC
  • Direct Connect + VPN = IPsec-encrypted private connection

Domain 3: Network Management and Operations — 20%

  • VPC Traffic Mirroring (mirror filter, mirror target, and mirror session)
  • Route 53 (health checks and DNS failover)
  • CloudWatch Logs + interface VPC endpoints
  • VPC Flow Logs for IP traffic

Domain 4: Network Security, Compliance, and Governance — 24%

  • Shield
  • WAF
  • Network Firewall
  • SGs + ACLs
  • Endpoints

中文版

考试

及格分数为 750 分。65 道题中有 50 道会计入分数。

领域 1：网络设计——30%

领域 2：网络实施——26%

  • TGW
  • Site-to-Site VPN = 本地环境 + Amazon VPC
  • Direct Connect + VPN = 采用 IPsec 加密的私有连接

领域 3：网络管理与运维——20%

  • VPC Traffic Mirroring（镜像筛选器、镜像目标和镜像会话）
  • Route 53（运行状况检查和 DNS 故障转移）
  • CloudWatch Logs + 接口 VPC 端点
  • 用于记录 IP 流量的 VPC Flow Logs

领域 4：网络安全、合规与治理——24%

  • Shield
  • WAF
  • Network Firewall
  • SG + ACL
  • 端点
